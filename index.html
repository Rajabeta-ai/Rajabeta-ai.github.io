Viral Ads Engine

Trend-to-ad pipeline for Indian Instagram · open source

Finds what is going viral, works out why, and writes the ad

PythonLLM classificationHikerAPIVeo 3.1Render

Every 3 hours it harvests Reels across 11 languages and 3 genres, and looks for posts whose reach far exceeds the creator's follower count: there the format carried the post, so the format is worth recreating. An LLM labels and clusters those formats into shootable recipes, then writes Veo prompts against each app's positioning and guardrails.

  1. Harvest
  2. Score: reach ÷ followers
  3. Label formats (LLM)
  4. Cluster recipes
  5. Veo prompts + guardrails
  6. Render + outro
Source code

The production deployment runs on private client configuration, so there is no public demo. A walkthrough is available on request.
